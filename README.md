# Car Decor Studio Website Case Study

## Overview
Car Decor Studio is a multi-brand car audio, lighting, interior comfort, and exterior styling accessories studio based in Siliguri, West Bengal. This project was a full client website build — a product-catalog website with a custom admin panel — designed to give the studio a professional online presence, make its full accessory range easy to browse by category, and turn visitors into WhatsApp enquiries.

## Key Features
- Premium automotive-themed homepage design
- Category mega-menu navigation (Audio, Lighting, Power, Interior, Exterior, Car Care)
- Full product catalog — 38+ products across 6 categories
- "Popular Picks" homepage showcase with bestseller badges
- One-click WhatsApp enquiry on every product, pre-filled with the product name
- Blog section for car care tips and buying guides
- About page with studio story and location details
- Contact page with click-to-call, WhatsApp, email, and embedded map
- Custom-built admin panel for managing products and site images without touching code
- Fully responsive layout across mobile, tablet, and desktop
- Optimized, compressed imagery for fast page loads
- Live website deployment

## Tech Stack
- HTML, CSS, JavaScript
- PHP (server-side rendering, custom admin panel)
- JSON-based product data store (no database required)
- GD image library (automatic image resizing & compression on upload)
- Session-based authentication with CSRF protection (admin panel)
- WhatsApp Business deep-linking for enquiries
- Responsive web design
- Live server deployment
- AI-assisted development (Claude)

## My Role
- Site structure, page layout, and content placement
- Built the product catalog system and converted static product listings into a data-driven template
- Designed and built a custom admin panel (login, product CRUD, image upload & management)
- Audited and fixed functional bugs (contact form, broken links) and accessibility issues
- Image pipeline cleanup — reformatted mislabeled files and compressed the full image library (~92% size reduction) with no visible quality loss
- Responsive design across breakpoints
- Deployment support and hosting handoff
